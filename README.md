# E-Commerce Sales Analysis

## Project Overview

This project analyzes e-commerce sales data to identify sales trends, profitable product categories, regional performance, customer behavior, and payment preferences.

The project uses Python, SQL, and Power BI to perform data cleaning, analysis, visualization, and dashboard creation.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQL
- SQLite
- Power BI
- Jupyter Notebook
